🛠️ KusinaERP — Setup ng Bagong Firebase / Database

Gamitin kapag ililipat sa ibang Firebase account (hal. email ng kumpanya / IT). Sundan mula 1 hanggang 5. Ang mga collection (table) ay awtomatikong nabubuo ng Firestore sa unang save — dito inihahanda ang mga kailangan para gumana agad.

1Gumawa ng Firebase project (isang beses, sa browser)

  1. Mag-login sa console.firebase.google.com gamit ang email ng kumpanya → Add project.
  2. Build → Authentication → Get started → i-enable ang Google (at Email/Password kung gagamitin).
  3. Sa Authentication → Settings → Authorized domains: idagdag ang domain ng site mo (hal. iyong-pangalan.github.io).
  4. Build → Firestore Database → Create database → Production mode → piliin ang pinakamalapit na region (hal. asia-southeast1).
  5. Project settings (⚙️) → Your apps → Web app (</>) → Register → kopyahin ang firebaseConfig.

2I-convert ang config → firebase-config.js

I-paste ang buong firebaseConfig na kinopya mo (kahit may const firebaseConfig =).

I-upload ito sa GitHub bilang firebase-config.js (papalitan ang luma) sa parehong folder ng admin.html.

3Gumawa ng firestore.rules para sa may-ari

Ang may-ari ang magiging unang Super Admin. Ilagay ang eksaktong email na ipang-lologin niya.

I-publish: Firebase Console → Firestore Database → Rules → i-paste → Publish. (Option: firebase deploy --only firestore:rules kung may Firebase CLI.)

4Ihanda ang database

Gawin lang ito pagkatapos ma-upload ang bagong firebase-config.js at ma-publish ang rules (Hakbang 2–3). Mag-sign in gamit ang email ng may-ari.





5Pagkatapos


    

  • Pumunta sa index.html, mag-login gamit ang email ng may-ari → Admin na siya.
    • 

  • Sa Admin → Users, idagdag at i-approve ang mga tao; Access Control para sa permissions.
    • 

  • Ilagay ang company info, mga branch, produkto, vendor, at POS Setup (SI Prefix / SI Next).
    • 

  • May test data na dati? Admin → Truncate → 🚀 Go-Live Reset para malinis at bumalik sa 1 ang SI number.
    • 



Hindi kayang gawin ng website na ito ang paggawa ng Firebase project, pag-enable ng Authentication, at pag-publish ng rules — kailangan ang mga iyon ng Firebase Console (isang beses lang). Lahat ng iba ay awtomatiko.
