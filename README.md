# KusinaERP Enterprise Suite (Full Flat Release v3)

Lahat ng 13 files ay nasa root directory para diretsong mai-upload sa GitHub nang walang folders.

### Kasama sa Release na ito:
1. **Google Sign-In + Required Password Setup**: Kapag nag-Google Login ang user sa unang pagkakataon, may lalabas agad na mandatory modal para mag-set up ng local password para sa backup at dagdag seguridad.
2. **Strict Firebase Authentication & Firestore Lookup**: Wala nang default/mock admin access kapag blangko. Lahat ay dumadaan sa `users` collection sa Firestore.
3. **10-Minute Auto-Logout**: May warning pop-up sa ika-9 na minuto at 60-second countdown.
4. **Accidental Exit Trap**: Browser back-button guard.
5. **e-POD & Offline Persistence**: Touchscreen signature canvas at exact device timestamping.
6. **Smart Analytics & Variance**: Pwedeng i-print at i-copy diretso sa Google Sheets (TSV format).
